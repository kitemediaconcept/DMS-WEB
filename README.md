# DMS-WEB

Diplomat Management Services (DMS Bahrain) - Strategic Business Support & Government Relations Portal.

## Overview
Official website and WordPress Elementor templates for **Diplomat Management Services Co. W.L.L. (Est. 1984)** in the Kingdom of Bahrain. Official Saudi Embassy Visa Agent and LMRA Registration Centre.

## Features
- **Grand Full-Width Hero Slider:** Interactive showcase inspired by Lulu Exchange corporate design with live progress bar tabs, counter, and touch/drag support.
- **Dynamic Scrolled Navigation Bar:** Full-width clean header at top that morphs smoothly into a floating glassmorphic rounded capsule pill navbar on scroll.
- **Apple SF Pro Display Typography:** Complete font integration across all pages for a clean, premium Apple design aesthetic.
- **Trust & Accreditations Section:** Experience that builds confidence with glowing emerald green aura feature cards and dot matrix grid pattern.
- **Comprehensive Multi-Page Architecture:**
  - `index.html` - Homepage with Hero Slider, Capability Search, Trust Accreditations, Services Grid, Story, and FAQ.
  - `about-us.html` - 40-year story, mission, founder legacy, and executive overview.
  - `categories.html` - Deep-dive into all 11 core service categories.
  - `blogs.html` - Bahrain business, Golden Visa, and visa insights.
  - `faq.html` - Full interactive accordion with categorized FAQs.
  - `contact-us.html` - Location, consultation form, direct phones, and WhatsApp.
- **Elementor Template Library:**
  - Complete `.json` Elementor template exports in `elementor-templates/`.
  - Separate Header & Footer zip package (`dms-header-and-footer.zip`).
  - All-in-one import bundle (`dms-elementor-templates.zip`).
  - Automatic synchronization script (`node sync-service.js`).

## Tech Stack
- Vanilla HTML5 & CSS3 (Custom design system with modern CSS variables)
- Native JavaScript ES6+ (Zero external bloat, lightweight micro-interactions)
- Apple SF Pro Display typography

## Local Development
To run locally:
```bash
npm start
```
Or open with any static server on port 3000 (`http://localhost:3000`).
